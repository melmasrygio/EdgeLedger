# EdgeLedger

EdgeLedger utilizes a distributed, event-driven architecture to optimize data and real-time validation, empowering a centralized Manager and Controller.

EdgeLedger is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/EdgeLedger.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

EdgeLedger is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
